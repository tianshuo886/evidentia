# paper-read · Paper Research OS (single-paper)

Deep-read a must-read paper PDF into a frozen Paper Model, Evidence Graph, and unified Kami reader.

- `/paper-read <pdf> --out <dir>` — blind deep read, project invisible
- `/paper-apply --paper <dir> --project <doc>` — contextual re-read → Research Delta

See `SKILL.md` for the full spec. Kami (`tw93/kami`) is presentation only, never truth.
`paperacquire` (`pa`) handles search/acquire upstream; this skill starts at the PDF.
